# MoonRay Documentation Home

![MoonRay]({{ "/assets/images/paper.png" | absolute_url }})


Welcome to the MoonRay Production Renderer documentation site!

**MoonRay** is an open-source project of the <a href="https://aswf.io">Academy Software Foundation</a>, supported by the <a href="https://linuxfoundation.org">Linux Foundation</a>. MoonRay was originally contributed by <a href="https://www.dreamworks.com/">DreamWorks Animation</a>, who uses MoonRay for all of their feature film production since [How To Train Your Dragon: The Hidden World](https://dreamworksanimation.com/movies/how-to-train-your-dragon-the-hidden-world). It also welcomes contributions from the open-source community.

MoonRay is released under the Apache 2.0 license. It includes:

- a production path-tracing renderer that runs on CPU and hybrid GPU (XPU) hardware.
- production-tested materials and a USD Hydra render delegate.
- tools for rendering, performance monitoring, and regression testing.
- local, multi-machine, and cloud rendering through the Arras system.
