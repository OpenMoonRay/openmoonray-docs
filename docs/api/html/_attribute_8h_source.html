32/**
33 * An Attribute object represents an attribute declared as part of a SceneClass,
34 * and tracks any metadata associated with it.
35 *
36 * Attribute objects are specific to the SceneClass in which they were declared.
37 * They cannot be constructed directly. They are constructed indirectly by
38 * declaring attributes through functions exposed by the SceneClass.
39 *
40 * There may be multiple SceneObjects with different values for the attribute,
41 * but there is only once instance of each Attribute object per SceneClass. The
42 * value of the Attribute is not stored in this class. It is stored in the
43 * SceneObject. The Attribute class just describes the attribute, keeping track
44 * of things like its name, default value, and associated metadata. Metadata is
45 * per attribute, not per attribute value.
46 *
47 * Thread Safety:
48 * - All data members (with the exception of metadata) are baked in at
49 * construction time. Since these data members are immutable, reading them
50 * from multiple threads without synchronization is safe.
51 * - Write access to metadata is not synchronized. It is not safe to write
52 * metadata from multiple threads simultaneously. You must synchronize
53 * this yourself.
54 * - Read access to metadata is provided through a const iterator, which is
55 * not invalidated after a write. Reading metadata from multiple threads
56 * without synchronization is safe. However, reading in the presence of
57 * a writer thread is not. A writer must lock out all readers.
58 */

315template <typename T>
316const T&
317Attribute::getDefaultValue() const
318{
319 // Sanity checks.
320 if (attributeType<T>() != mType) {
321 std::stringstream errMsg;
322 errMsg << "Attribute::getDefaultValue() invoked with incorrect type '" <<
323 attributeTypeName<T>() << "'. Attribute '" << mName <<
324 "' is of type '" << attributeTypeName(mType) << "'.";
325 throw except::TypeError(errMsg.str());
326 }
327
328 return *static_cast<T*>(mDefault);
329}
