Detailed Description

template<typename T>
class moonray::time::RAIIInclusiveExclusiveTicker< T >

This is similar to the RAIITicker but also takes care to decrement the parentStat's exclusive tick count.

You would use this ticker when you have parent-task/child-task relationships in your timings and would like the parent to not include the time spent in the child.
