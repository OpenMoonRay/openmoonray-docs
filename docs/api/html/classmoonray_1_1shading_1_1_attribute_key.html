Detailed Description

a light weight index with type/name/size info for fast lookup primitive attributes

An AttributeKey is an index into a table of primitive attributes. It is very lightweight (just an int) and can be cheaply copied. The index points into a table of names, data types and data sizes for each key. The table is a set of static member variables which should only be modified by StandardAttributes::init() sometime at startup. It would be desirable to merge this class with scene_rdl2::rdl2::AttributeKey, as they serve very similar purposes.
