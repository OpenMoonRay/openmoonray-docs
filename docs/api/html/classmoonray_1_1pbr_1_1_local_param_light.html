Initialize the transform and parametrization members below, as well as mPosition, mOrientation, mDirection, and mMb in the base class

General comment and warning! The term "local" when used by lights and the various transformation functions does not necessarily mean the usual rdl local space of the light object. Rather, it refers to a convenient local light space used by the light computation code. It it probably more properly named "lightLocal" space - but that is a bit much verbosity.
