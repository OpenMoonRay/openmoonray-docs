Detailed Description

A RootShader is a Shader object that could potentially be the root of a shader graph. These Shaders can be assigned in a layer, and be looked up from a layer using an assignment id. See Layer.h for more details. Subclasses of RootShader include Displacement, Material, and VolumeShader, which all define the "look" of a geometry.
