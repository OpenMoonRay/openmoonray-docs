Detailed Description

A utility object that can sample according to a piecewise constant 2D distribution.

Member Enumeration Documentation

◆ Mapping

enum moonray::pbr::Distribution2D::Mapping
Enumerator
NONE 

Undefined / un-initialized.

PLANAR 

Weighted by the image luminance, no-op.

CIRCULAR 

Used for disk light texture sampling, pixels outside of a maximal inscribed circle are set to black so we don't sample them.

HEMISPHERICAL 

Assuming a latlong input, the upper half of image is weighted by math::sin(2pi * v), see (see pbrt section 14.6.5). The bottom half of image is set to zero so it's not accessed. (Currently the memory for the bottom half of the image weights goes to waste)

SPHERICAL 

Weighted by the image luminance * math::sin(2pi * v) over the full image.

Continuous sampling: returns the continuous variable u in [0,1), with density proportional to the distribution, that corresponds to the uniform parameter ru in [0,1) (and similarly for v & rv). These (u,v) values are passed back in *uv. The pointer uv must be non-null. Optionally returns the pdf of sampling this segment of the distribution
