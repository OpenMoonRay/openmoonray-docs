77//-------------------------------------------------------------------------------------
78//
79// Contains a fixed-size array of data and a ChannelSet
80// defining the active channels.
81//
82// Intentionally similar to Nuke's DD::Image::Pixel class.
83//
84// NOTE: This class is solely intended for use in image processing algorithms and
85// *not* for multi-pixel data storage (ex. a line or tile's worth.)
86//
87// (TODO: is it worth it to change this class to a packed channel array? Likely not
88// as managing the data packing/unpacking may be far more trouble than it's worth)
89//
90//-------------------------------------------------------------------------------------
91
