69/// @brief A BsdfSampler object is a helper class used to efficiently sample
70/// multi-lobe bsdfs, using Veach's multi-sample model.

72/// good stratification of lobe sampling, giving at least one

74/// variable number of samples for other lobes. It also rounds the number of
75/// sample per lobe to a power of two and enforces other sample count
76/// constraints.
