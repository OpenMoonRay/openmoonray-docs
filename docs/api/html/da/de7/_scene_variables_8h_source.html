61/**
62 * The SceneVariables are a SceneObject which contain render globals. This
63 * object is created by the SceneContext when it is constructed, and the context
64 * enforces that no additional SceneVariables objects are created (it's a
65 * singleton within the SceneContext). Its name is "__SceneVariables__", but
66 * you don't need to remember that because you can access the object directly
67 * from the SceneContext.
68 *
69 * Thread Safety:
70 * - The guarantees are exactly the same as any other SceneObject. There is
71 * no sychronization from RDL on accessing or modifying SceneObjects once
72 * you get the pointer back from the SceneContext.
73 * - During rendering, accessing the SceneVariables from multiple threads is
74 * safe because the whole context is const and nobody is updating it.
75 * In areas where the context is not const (outside the render loop),
76 * synchronization is up to you.
77 */
