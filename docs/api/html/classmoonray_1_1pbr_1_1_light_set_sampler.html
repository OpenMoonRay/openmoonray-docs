Detailed Description

A LightSetSampler object is used to efficiently sample a LightSet, using Veach's multi-sample model. It uses light importance sampling, but also enforces good stratification of light sampling, giving at least one sample per active light, at most one sample per delta light, and a variable number of samples for other lights. It also rounds the number of sample per lobe to a power of two and enforces other sample count constraints. This class lets the integrator:

  • Setup a maximum number of samples per light
  • Generate / Iterate over light-set samples, retrieving light properties for the current sample
