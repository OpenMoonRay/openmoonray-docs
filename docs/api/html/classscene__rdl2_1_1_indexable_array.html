Detailed Description

template<typename T, typename Hash = std::hash<T>, typename KeyEqual = std::equal_to<T>>
class scene_rdl2::IndexableArray< T, Hash, KeyEqual >

A class that mostly acts like a std::vector, except it also allows for constant-time lookup of the vector index by value. I.e. It allows for bidirectional constant-time lookup either through array index or value.

Do not modify the order of the array (e.g. std::sort(a.begin(), a.end())). This will break the class invariant. (In fact, the class does not provide non-const iterators for this reason).
