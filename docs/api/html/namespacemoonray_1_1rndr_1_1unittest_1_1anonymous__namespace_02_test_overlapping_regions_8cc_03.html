This test mimics what happens in AdaptiveRegions, where a tile informs the region that it is done rendering. AdaptiveRegions keeps a count of the number of tiles in each region, and when all of the tiles in the region have been updated, the corresponding tree is locked and updated. This code mimics counting the number of tiles that pass through a region.
