11/*
12 * This file is used to compensate for energy loss from
13 * microfacet transmission lobes as outlined in Walter'07.
14 * We use the Kelemen'01 energy compensation BRDF as described in
15 * Kulla'17 to be added to the regular microfacet lobe.
16 * This file describes the energy to be added in reflection and
17 * transmission to be perfectly energy 'preserving'.
18 * It provides a factor used to calculate the energy
19 * distribution between the two that follows reciprocity and is based
20 * on average fresnel reflectance parameterized by (etaT/etaI).
21 * It also provides sampling curves, PDF and a one-sample weight to sample
22 * the reflection term efficiently.
23 * Ref:
24 * Revisiting Physically Based Shading, PBS Kulla'17
25 */
