Detailed Description

By "localize" we mean "copy all the external assets that a scene references to a single location". Essentially we are isolating a scene such that all its asset data and the RDL data lives in the same directory. (Unfortunately this will not help your scene speak new languages. Bummer!)

A localizer can localize RDL2 input files, writing the localized result to the given output file. Multiple files can be localized with the same localizer, though configurable options are fixed at construction time.
