10/**
11 * rt library provides acceleration data structures and interface for:
12 * - Efficient building of acceleration data structures.
13 * - Efficient intersection ray queries.
14 *
15 * The rt library primarily interacts with the geom library where it obtains
16 * geometry data to build the acceleration data structures.
17 * The user should understand that rt library has a <b>strong</b>
18 * dependency on the geom library, not only during the build stage of the
19 * acceleration data structure, but also during intersection queries.
20 * Therefore it's important for the user of the rt and geom libraries to
21 * maintain data consistency between the two.
22 */
