Detailed Description

This class represents the mapping from each sub-primitive (face/curve) to a corresponding layer assignment id. Each primitive is constructed with one LayerAssignmentId so that it can locate the material shader assignment for each sub-primitive. If the whole primitive shares one material assignment, one ValueType is used to represent the id (CONSTANT). If the primitive is composed of several parts, a std::vector<ValueType> with size of sub-primitive count (for example, curves count in Curves primitive) is used to represent the id (VARYING)
