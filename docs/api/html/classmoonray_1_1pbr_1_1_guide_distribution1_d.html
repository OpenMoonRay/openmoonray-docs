Detailed Description

A utility object that can sample according to a a piecewise constant 1D distribution. This class uses the method of guide table from Chen and Asau (1974): Chen, H.-C. and Asau, Y. (1974). On generating random variates from an empirical distribution. AIEE transactions, 6:153–166. We store a cdf table and a guide table of the same size.
