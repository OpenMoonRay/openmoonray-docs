42 // Initialize the object and attempt to load grid. This
43 // function must be called first. If initialization fails
44 // this object is left in an invalid state.
45 // ------------------------------------------------------------------------
46 // 'filename' - The name of the .vdb file to load.
47 // 'gridName' - If blank, the first grid in the .vdb file will be used. If
48 // non-bank, there must be a grid within the .vdb file whose
49 // name matches the name given. If there are multiple grid's in
50 // the .vdb with the same name, they can be individually
51 // accessed by appending an index operator to the grid name,
52 // eg. density[1].
53 // 'render2world' - A ptr to a matrix responsible for transforming the
54 // coordinate from render space to world space. If null is
55 // passed, the coordinate is assumed to be given in world space.
56 // 'grid2world' - A ptr to a matrix responsible for appending an additional
57 // transform to the grid, in adddition to that stored in the
58 // .vdb file. If null is passed, no additional transformation
59 // is applied.
60 // 'errorMsg' - A string that will contain an error message if
61 // initialization fails.
62 // ------------------------------------------------------------------------
63 //
64 // Returns true if the grid is successfully loaded, otherwise false with
65 // a (hopefully) informative error message.
66 //
67 bool initialize(const std::string &filename,
68 const std::string &gridName,
69 const scene_rdl2::math::Mat4d *render2world,
70 const scene_rdl2::math::Mat4d *grid2world,
71 std::string &errorMsg);
72
