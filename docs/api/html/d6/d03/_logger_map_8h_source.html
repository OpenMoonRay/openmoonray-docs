19// A singleton class that holds a map between filenames and logger names. It
20// is used to to allow multiple filenames to map to the same logger, allowing
21// users to group the logging output of multiple files into components.
22// If a file is added multiple times with different Loggers, only the final
23// insertion will be used (as per std::map behavior).
