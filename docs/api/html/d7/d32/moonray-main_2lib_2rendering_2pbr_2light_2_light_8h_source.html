100 /// Intersection and Sampling API
101 /// IMPORTANT: The API below operates entirely in render space. All positions
102 /// and directions passed in / returned are in render space.

104 /// Can this light illuminate point p with surface normal n (ignoring
105 /// occlusion consideration)?
106 /// This function is used to perform early culling checks to avoid
107 /// integrating lights when they can't affect the result.
108 /// Passing in the the normal is optional. We can do a better job on culling
109 /// if n is present for some light types.
110 /// The radius defines a spherical region around p in which case
111 /// the light should not be culled if any portion of that spherical region
112 /// can be illuminated by this light (this is necessary so the culling
113 /// calculations are accurate with sub-surface scattering).
114 virtual bool canIlluminate(const scene_rdl2::math::Vec3f p, const scene_rdl2::math::Vec3f *n, float time,

143 /// Compute whether the ray (p, wi) intersects the light, within the given
144 /// maxDistance. If the actual distance is equal to maxDistance, then we
145 /// count that as a hit. If the light is hit, the function also returns the
146 /// corresponding intersection.
147 ///
148 /// Intersection tests are performed first against the bounded lights (cylinder,
149 /// disk, rect, sphere, spot) using an Embree acceleration structure. If no
150 /// such intersections are found, it will proceed to iterate over the unbounded
151 /// lights (distant, env) until the first one hit.
152 virtual bool intersect(const scene_rdl2::math::Vec3f &p, const scene_rdl2::math::Vec3f *n,
153 const scene_rdl2::math::Vec3f &wi, float time,
154 float maxDistance, LightIntersection &isect) const = 0;
155
156 /// Sample a position on the light and return true if the sample can
157 /// contribute radiance to the point p, and false otherwise (i.e. if the
158 /// light sample is facing away from point p or if the light was unable to
159 /// draw a sample).
160 ///
161 /// When it returns true, the method also returns the direction wi from
162 /// the point p on the surface, to the sampled position as well as the
163 /// resulting light intersection.
164 ///
165 /// The n parameter (also optional as in canIlluminate) defines the
166 /// hemisphere of directions that can be seen from point p. If non-null,
167 /// Lights can test that the sampled direction is within that hemisphere
168 /// and return true / false to respectively accept / cull the sample.
169 ///
170 /// This result assumes visibility: occlusion is only tested later if the
171 /// contribution is actually significant.
172 /// TODO: later we may need a 3D sample value and a component in the
173 /// intersection, when dealing with geometry lights.
174 virtual bool sample(const scene_rdl2::math::Vec3f &p, const scene_rdl2::math::Vec3f *n, float time,
175 const scene_rdl2::math::Vec3f& r,
176 scene_rdl2::math::Vec3f &wi, LightIntersection &isect, float rayDirFootprint) const = 0;
177
178 /// Evaluate the light's emitted radiance from the intersection position
179 /// in the direction -wi (make sure to pass-in the same wi that was passed-in
180 /// the intersect() call or returned from the sample() call above).
181 /// Also compute the probability density of sampling this direction from the
182 /// point p (density measured wrt. solid angle).
183 /// See intersect() for more info on the fromCamera toggle.
184 /// @@@ TODO: Expand interface to take texture differentials.
185 ///
186 /// The fromCamera toggle is set to true when visualizing lights visible
187 /// in camera. Some lights require a specific implementation in this context.
188 /// Most light types are unaffected. SpotLights are the current exception
189 /// due to not being able to see any radiance when outside of their outer
190 /// field of view.
191 virtual scene_rdl2::math::Color eval(mcrt_common::ThreadLocalState* tls, const scene_rdl2::math::Vec3f &wi,
192 const scene_rdl2::math::Vec3f &p, const LightFilterRandomValues& filterR,
193 float time, const LightIntersection &isect, bool fromCamera,
194 const LightFilterList *lightFilterList, float rayDirFootprint,
195 float *pdf = nullptr) const = 0;
196
197 /// Query a position from light that will be used as pivot point for
198 /// equi-angular sampling (part of volume scattering integration)
199 /// For most of the lights this is a uniform area sampling,
200 /// but for sphere light we intentionally use sphere center as pivot
201 /// For detail reference see:
202 /// "Importance Sampling Techniques for Path Tracing in Participating Media"
203 /// EGSR2012 Christopher Kulla and Marcos Fajardo
204 virtual scene_rdl2::math::Vec3f getEquiAngularPivot(const scene_rdl2::math::Vec3f& r, float time) const = 0;
