Private helper function for rgbToHsv() and rgbToHsl(). Converts an RGB color value to its corresponding hue.

r, g, and b are assumed to be [0, 1]. hue is returned between [0, 1]. Hue is determined by warping the hexagonal projection of the RGB cube into a circle. Hue is the resulting angle of the projected RGB vector around the origin of the HSV circle.
