Detailed Description

an enumeration of standard primitive attributes that can be used directly without further declaration

This is an enumeration of all the standard primitive attributes that can be used. Additional keys should be added as needed (with a corresponding change to init()). This list of keys is initialized in init() and init() should be called before using any of these keys.
