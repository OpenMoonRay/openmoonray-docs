Detailed Description

A layered dielectric fresnel reflectance object. From "Physically-Accurate Fur Reflectance: Modeling, Measurement and Rendering" Eqn (6) and (7) Models multiple layers of dielectric slabs with air outside both sides of each layer. These properties increase reflectance compared to Fresnel reflectance from a dielectric interface.
