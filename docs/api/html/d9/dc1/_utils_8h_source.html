97/**
98 * Scans the given SceneVariables for the frame range (minfield to maxfield,
99 * inclusive) and the motion steps, and constructs a list of unique motion
100 * sample numbers that cover the entire frame range. (If no frame range is set,
101 * the current frame is used.)
102 *
103 * For example, given the following settings:
104 * minfield = 101
105 * maxfield = 103
106 * motion steps = -1, 0
107 *
108 * The non-unique list of motion sample numbers would be the following:
109 * 100, 101, 101, 102, 102, 103
110 * | | | | | |
111 * (-1) (0) (-1) (0) (-1) (0) // motion step
112 * 101 102 103 // frame number (in range 101 -> 103)
113 *
114 * The *unique* list of these motion sample numbers excludes duplicates which
115 * represent the same data at the same point in time.
116 * 100, 101, 102, 103
117 *
118 * An example use case for this would be to get all the unique motion sample
119 * numbers and plug them into replacePoundWithSampleNumber(). When replaced
120 * into a file path, that would give you all the possible file paths the
121 * renderer might access for that asset across all the frames in the frame
122 * range.
123 */
124FloatVector
125uniqueSampleNumberRange(const SceneVariables& sceneVars);
