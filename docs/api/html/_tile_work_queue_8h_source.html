33// This is a shared queue which hands out work for all the render threads on request.
34// Along with queue draining, it is the mechanism we use to load balance the work
35// amongst threads. It's a virtual queue in that it looks like a queue to the outside

37// these are synthesized given an atomic incrementing counter and the current list
38// of passes and tiles for the frame.
39//
