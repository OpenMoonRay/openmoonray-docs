Crawl all internal renderOutput AOV buffers and calls one of the user defined function based on the AOV type for every AOV buffer. This template is useful if you would like to do something for every AOVs inside renderOutputDriver.

Parameters

funcVisVarianceexecute function if AOV buffer is Visibility Variance type
funcVarianceexecute function if AOV buffer is Variance type
