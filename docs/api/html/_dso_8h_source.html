24/**
25 * A Dso represents a dynamically loaded shared library that contains the
26 * definition of a new RDL object type that derives from the existing RDL
27 * object hierarchy. It is the point of runtime customization for objects in
28 * the scene.
29 *
30 * RDL DSOs don't use this class directly. Rather, this class represents a
31 * DSO that has been loaded that RDL wishes to use. It loads symbols lazily
32 * to avoid dragging in big library dependencies from custom types.
33 *
34 * The search path for DSOs is a colon separated list of directory paths,
35 * similar to the $PATH variable in your shell.
36 *
37 * Thread Safety:
38 * - The Dso class makes no attempt to keep a registry of loaded DSOs or
39 * make the process of opening DSOs thread safe. Synchronization of these
40 * Dso objects should happen at a higher level.
41 * - In the context of RDL, this synchronization happens in the SceneContext.
42 * The context has a concurrent hash map of SceneClasses, and we only
43 * construct (and thus, open) a DSO if we have a write accessor to the
44 * given class name key. This effectively gives us a lock on DSOs with
45 * that given name, and gets around any thread safety issues.
46 */
47class Dso
48{
49public:
50 /**
51 * Attempts to locate, open, and extract the rdl_declare() symbol for an
52 * RDL SceneClass with the given name and potential search path. The name
53 * should be the class name. The ".so" extension is appended to the class
54 * name when searching for the DSO.
55 *
56 * @param className The name of the SceneClass you are trying to load.
57 * @param searchPath Colon separated list of potential paths on the file
58 * system.
59 * @param proxyModeEnabled If true, it searches for the DSO with a
60 * ".proxy" extension.
61 * @throw except::IoError If the DSO could not be found in the search
62 * path, or it could not be dlopen()'d.
63 * @throw except::RuntimeError If the rdl_declare() symbol could not
64 * be loaded from the DSO.
65 */
66 Dso(const std::string& className, const std::string& searchPath,
67 bool proxyModeEnabled = false);
68
69 /**
70 * Closes the DSO if it was successfully opened.
71 */
72 ~Dso();

74 /**
75 * Extracts the rdl2_declare() function from the DSO and returns a function

77 *
78 * @return A function pointer to the rdl2_declare() function.
79 * @throw except::RuntimeError If the "rdl2_declare" symbol cannot be
80 * extracted from the DSO.
81 */
82 ClassDeclareFunc getDeclare();

88 * @return A function pointer to the rdl2_create() function.

91 */
92 ObjectCreateFunc getCreate();
93

98 * @return A function pointer to the rdl2_destroy() function.
99 * @throw except::RuntimeError If the "rdl2_destroy" symbol cannot be

102 ObjectDestroyFunc getDestroy();

107 /**
108 * Takes a file path and attempts to open it as an RDL DSO. If this
109 * succeeds, the DSO is closed and we return true. If any part of this
110 * fails, we catch the exceptions and return false.
111 *
112 * This only verifies that the DSO correctly exports the rdl2_declare()
113 * symbol. It's still possible that it has broken rdl2_create() and
114 * rdl2_destroy() functions. This guarantees that, at a minimum, we can use
115 * the DSO with proxy objects.
116 *
117 * @param filePath Path to a file that we'll attempt to open as an RDL DSO.
118 * @param proxyModeEnabled True if we're testing proxy DSOs.
119 * @return True if the file appears to be a valid RDL DSO.
120 */
121 static bool isValidDso(const std::string& filePath, bool proxyModeEnabled = false);
122
123 /**
124 * Takes a file path and returns the class name of the DSO
125 *
126 * @param filePath Path to a file that we'll attempt to open as an RDL DSO.
127 * @return The name of the DSO Class, or empty string on failure
128 */
129 static std::string classNameFromFileName(const std::string& filePath);
