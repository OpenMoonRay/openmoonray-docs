14//
15// mTopLevelTls Backpointer to top level TLS.
16// mRayStatePool Pooled memory allocator.
17// mCL1Pool Single cache line allocator.
18// mPrimaryRayQueue All local primary rays are sent through this queue.
19// mIncoherentRayQueue All local incoherent/indirect rays are sent through these queues.
20// mOcclusionQueue All local occlusion queries are sent through this queue.
21// mRadianceQueues All local radiance samples are sent through these queues,
22// mAovQueues there is one queue per film.
23// mHeatMapQueues
24// mXPUOcclusionRayQueue Pointer to XPU occlusion ray queue (owned by the RenderDriver)
25// mPrimaryRaysSubmitted Primary rays submitted from Film index 0. This is the only film we use to track progress.
26// mFs Constant for entire frame.
27// mNonBundledFilmIdx It's only valid to access this member when in non-bundled mode! Contains the index of the film we're rendering to.
28// mTilesRenderedTo Tiles which have had any samples rendered to them for gui diagnostics purposes.
29// mCancellationState
30// mCurrentPassIdx The current pass we are rendering.
31// mStatistics
32// mRayRecorder Ray recording functionality.
33// mRayVertexStack
34// mPrimaryRayEntries
35// mOcclusionEntries
36// mPresenceShadowsEntries
37// mRadianceEntries
38// mAovEntries
39// mHeatMapEntries
40//
