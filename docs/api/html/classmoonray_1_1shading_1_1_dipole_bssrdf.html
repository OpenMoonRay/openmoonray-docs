Detailed Description

Derived class to implement the dipole Bssrdf with importance sampling.

This Bssrdf implements the dipole approximation as in (multiple scattering only, single scattering is ignored): [1] "A Practical Model for Subsurface Light Transport", Jensen et al., Siggraph 2001

It implements an exact dipole importance sampling scheme for local multiple scattering is described in: [2] "Efficient Rendering of Local Subsurface Scattering", Mertens et al., Pacific Conference on Computer Graphics and Applications, 2003

It uses optionally the Bssrdf re-parameterization described in: [3] "A Rapid Hierarchical Rendering Technique for Translucent Materials", Jensen & Buhler, Siggraph 2002
