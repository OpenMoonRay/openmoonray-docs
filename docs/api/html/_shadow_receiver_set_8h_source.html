15/**
16 * The ShadowReceiverSet inherits from the GeometrySet. Just like the
17 * GeometrySet, it is a collection of geometries with no
18 * duplicates. It it used for per part assignments in the Layer.
19 * It can be reused for multiple Layer assignments.
20 *
21 * The purpose of the ShadowReceiverSet is to specify which geometries
22 * won't receive a shadow from specified other geometries or
23 * their parts. Curently this shadow suppression is only
24 * supported for shadow receivers which are geometries with
25 * assigned volumes (since the feature request ticket
26 * MOONRAY-4130 specifically requested this feature for
27 * volumes).
28 *
29 * For example, suppose we define the following ShadowReceiverSet:
30 *
31 * rcvrSet1 = ShadowReceiverSet("ShadowReceiverSet") {
32 * geom1,
33 * }
34 *
35 * where geom1 is a geometry with a volume assigned to it. Then,
36 * we can put the following 4 geoms in a layer:
37 *
38 * Layer("Scene/layer") {
39 * {geom2, "", mtl1, lgtSet1},
40 * {geom3, "", mtl1, lgtSet1, rcvrSet1},
41 * {geom4, "partA", mtl1, lgtSet1, rcvrSet1},
42 * {geom5, {"partB", "partC"}, mtl1, lgtSet1, rcvrSet1},
43 * }
44 *
45 * The results will be as follows:
46 * geom2, having no assigned ShadowReceiverSet, casts shadows
47 * normally.
48 * geom3 has rcvrSet1 assigned, so its shadows which would
49 * normally cast onto the geoms in rcvrSet1 (i.e. geom1), from
50 * any lights, will be suppressed.
51 * For geom4, only partA will have its shadows onto geom1
52 * suppressed - other parts of geom4 will cast normally.
53 * And for geom 5, only partB and partC will have their shadows
54 * onto geom1 suppressed.
55 *
56 * */
