Detailed Description

template<typename T, template< typename, typename > class Traits, typename Allocator = scene_rdl2::alloc::AlignedAllocator<T, SIMD_MEMORY_ALIGNMENT>>
class moonray::geom::VertexBuffer< T, Traits, Allocator >

Provides a vertex buffer in which the layout may vary at compile time. The layout is (mostly) hidden to the user. The only difference between layouts in the public API are the data calls.
