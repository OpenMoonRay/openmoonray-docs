314 // This sample position is used for sampling a primitive's vdb grids. It must be in the vdb grids'
315 // space. VdbVolume primitives have several vdb grids: e.g. density, albedo, and emission.
316 // For VdbVolume, these grids have a unique "grid space", aka local space. Mesh primitives have a
317 // "baked density" grid, whose space is conveniently the same as render space.
318 virtual scene_rdl2::math::Vec3f evalVolumeSamplePosition(mcrt_common::ThreadLocalState* tls,
319 uint32_t volumeId,

325 virtual scene_rdl2::math::Vec3f transformVolumeSamplePosition(const Vec3f& pSample, float /* time */) const
326 {
327 return pSample;

330 // Evaluate volume density from volume shader or vdb grid. For VdbVolumes, pSample
331 // is in world space. For all other primitives pSample is in render space. This is
332 // because the density grid is stored in world space in VdbVolume and it is stored in
333 // render space for all other primitives.
