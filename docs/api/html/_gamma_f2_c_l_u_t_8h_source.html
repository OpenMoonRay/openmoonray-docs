16// -- Generating lookup table for conversion from linear float to gamma 2.2 uchar
17//
18// This class is designed for generating lookup table for direct conversion from 32bit
19// single float (linear space) to 8bit unsigned char with gamma 2.2 conversion.
20// Also includes several different test and verify functions.
21//
22// This class is not used runtime of moonray. But I would like to keep this code inside
23// moonray because it's very useful to understand basic idea of direct float to uchar
24// lookup table for gamma 2.2 correction. Toshi (Jan/03/2018)
25//
26// I tested several versions and finally found 15bitLUT version is fastest.
27// So I'm currently using 15bitLUT by GammaF2C::g22().
28// LUT is generated by GammaF2CLUT::tblGen15bit() and id is computed by GammaF2CLUT::calcTblId3()
29// Toshi (Mar/01/2018)
30//
31class GammaF2CLUT
32{
33public:

42 mUni.mI = (((signBit & 0x1) << 31) | ((exponent & 0xff) << 23) | (mantissa & 0x7fffff));
