Converts an HSL color value to RGB.

h, s, and l are assumed to be [0, 1]. h, s, l values outside of [0, 1] are handled as well as they can be. r, g, b are in [0, 1] given legal h, s, l values.

◆ rgbToHue()

float scene_rdl2::math::rgbToHue ( const Color &  c)

Converts a Color to its corresponding hue.

r, g, and b values are assumed to be [0, 1]. Hue is returned between [0, 1]. Hue is determined by warping the hexagonal projection of the RGB cube into a circle. Hue is the resulting angle of the projected RGB vector around the origin of the HSV circle.

[in]cRGB color
Returns
