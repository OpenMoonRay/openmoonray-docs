26/**
27 * The GeometrySet represents a collection of Geometries with no duplicates.
28 * It's used for building BVHs over a set of spatially local Geometries, where
29 * building trees for each Geometry would result in a lot of spatial overlap.
30 *
31 * It only has one attribute, named "geometries", which is a SceneObjectIndexable.
32 * We provide convenience functions on the GeometrySet to add and remove Geometries
33 * from the set, as well as check if a Geometry is contained in the set. Please use these
34 * functions to maintain the geometries' uniqueness invariant. When setting "geometries"
35 * directly, make sure the light filters are unique and their order is deterministic.
36 *
37 * You can get the Geometries as a const SceneObjectIndexable& with the getGeometries() method call.
38 */
39class GeometrySet : public SceneObject
40{
41public:
42 typedef SceneObject Parent;

50 /**
51 * Adds the given Geometry to the GeometrySet, if it is not already a member
52 * of the set. If it is already a member of the set, this does nothing.
53 *
54 * @param geometry The Geometry to add to the GeometrySet.
55 */
56 void add(Geometry* geometry);
57
58 /**
59 * Removes the given Geometry from the GeometrySet, if it is already a
60 * member of the set. If it is not a member of the set, this does nothing.
61 *
62 * @param geometry The Geometry to remove from the GeometrySet.
63 */
64 void remove(Geometry* geometry);

66 /**
67 * Returns true if the given Geometry is a member of the GeometrySet.
68 * There's no need to call this before calling add() or remove(), as they
69 * will gracefully handle those edge cases.

71 * @param geometry The Geometry to check for membership.
72 * @return True if the geometry is a member of the GeometrySet.
73 */
74 bool contains(const Geometry* geometry) const;

84 * manually on a specific object (see SceneContext::applyUpdates())
85 *
86 * This is a non-recursive version of updatePrep(). This is needed to handle the
87 * case for Layer and GeometrySet, for which we have already looped on

91 * @param sceneObjets UpdateHelper passed from SceneContext.cc
