55
56 PyBinaryReaderClass_t("BinaryReader",
57 "A BinaryReader object can decode a binary stream of RDL data into a SceneContext. "
58 "It can be used to load a SceneContext from a serialized file, apply incremental "
59 "updates from a network socket, etc. \n"
60 "\n"
61 "Since BinaryReader needs to make modifications to the SceneContext, it cannot "
62 "operate on a const (read-only) context. It must be used at a point where "
63 "the SceneContext is mutable. \n"
64 "\n"
65 "The BinaryReader maintains no state other than the SceneContext it is supposed "
66 "to modify, so keeping it around to apply multiple incremental updates to the "
67 "SceneContext should work just fine. \n"
68 "\n"
69 "The BinaryReader can handle binary data from a number of sources. There are "
70 "convenience functions for reading RDL data from a file or a generic input "
71 "stream. These methods handle proper framing of the RDL binary data. The method "
72 "which reads binary data directly from byte strings assumes the framing has already "
73 "been removed and the appropriate manfiest and payload buffers have been extracted. \n"
74 "\n"
75 "RDL framing is very simple, so if you want to handle it at a higher level and "
76 "read directly into byte strings it's not very hard. The frame looks like this: \n"
77 "\n\n"
78 " +---------+---------+------------+------------+ \n"
79 " | mlen | plen | manifest | payload | \n"
80 " +---------+---------+------------+------------+ \n"
81 " | 8 bytes | 8 bytes | mlen bytes | plen bytes | \n"
82 " +---------+---------+------------+------------+ \n"
83 " ^-- first byte last byte --^ \n"
84 "\n\n"
85 "NOTE: Both mlen and plen are 64-bit unsigned integers, in network byte order (big endian). \n"
86 "\n"
87 "This encoding allows us to easily read the manifest and payload into separate buffers. "
88 "The manifest must be decoded serially, but once decoded, we have offsets into each message "
89 "in the payload, so we can decode it in parallel. \n"
90 "\n"
91 "Thread Safety: \n"
92 " - The SceneContext guarantees that operations that the BinaryReader takes (such as "
93 "creating new SceneObjects) happens in a threadsafe way. \n"
94 " - Manipulating the same SceneObject in multiple threads is not safe. As such, "
95 "a binary RDL file with multiple copies of the same SceneObject may cause thread unsafety "
96 "in the BinaryReader if those updates are decoded in parallel. The BinaryWriter will "
97 "never produce such files, but it's something to keep in mind. \n"
98 " - Since the BinaryReader writes into SceneContext data (in particular, SceneObjects), "
99 "it is not safe to be mucking about with that data in another thread while the "
100 "BinaryReader is working.",
101 bp::init<std::shared_ptr<rdl2::SceneContext>>( bp::arg("SceneContext") ))
102
103 .def("fromFile",
104 &PyBinaryReader::fromFile,
105 bp::arg("filename"),
106 "Opens the file with the given filename and attempts to read its contents as a stream of RDL "
107 "binary."
108 "\n"
109 "Input: filename The path to the RDL binary file on the filesystem.");
