62 //
63 // We have 4 different types of precision control options for PackTile encoding.
64 // Basically, AUTO16 is the best option and we can achieve minimum data transfer size always.
65 // Other options are mostly designed for comparison and debugging purposes.
66 // The only drawback of AUTO16 is the runtime computation cost. Some AOV has
67 // scene_rdl2::grid_util::CoarsePassPrecision::RUNTIME_DECISION setting and this requires
68 // HDRI pixel test every time inside the encoding phase. Obviously, this test needs extra
69 // overhead costs. At this moment, this overhead is in acceptable range.
70 // It would be better if we add a new mode that skip RUNTIME_DECISION setting here when we can
71 // use drastically increased network bandwidth in the future.
72 //
73 enum class PrecisionControl : char {
74 FULL32, // Always uses F32 for both of Coarse and Fine pass
75
76 FULL16, // Always uses H16 if possible for both of Coarse and Fine pass.
77 // However, uses F32 if minimum precision is F32
78
79 AUTO32, // CoarsePass : Choose proper precision automatically based on the AOV data
80 // FinePass : Always uses F32
81
82 AUTO16 // CoarsePass : Choose proper precision automatically based on the AOV data
83 // FinePass : Basically use H16. Only uses F32 if minimum precision is F32
84 };
