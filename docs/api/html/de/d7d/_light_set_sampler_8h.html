class  moonray::pbr::LightSetSampler
 A LightSetSampler object is used to efficiently sample a LightSet, using Veach's multi-sample model. It uses light importance sampling, but also enforces good stratification of light sampling, giving at least one sample per active light, at most one sample per delta light, and a variable number of samples for other lights.
