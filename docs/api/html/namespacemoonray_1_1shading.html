 normalized (N.L)^Exponent lobe This lobe creates a Phong-like specular lobe, but along the surface normal instead of the 'reflection vector'. It is called "EyeCaustic" because it is empirically modeled based on the caustics observed in eyeballs from refractions through the cornea.
