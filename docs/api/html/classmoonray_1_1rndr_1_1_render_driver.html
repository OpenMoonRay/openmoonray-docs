◆ initRenderDriver

void initRenderDriver ( const mcrt_common::TLSInitParams &  initParams)
friend

Internal version of initRenderDriver that takes a configured TLSInitParams. Generally used by unit tests. This must be called at program startup before we create any RenderContexts. It creates a single global render driver which is shared between all future render contexts. Internally this also sets up all or our TLS objects.
