468 # code of the BuildIspcDsoSource() function should trigger a rebuild of
469 # the builder's targets, but it is not smart enough to know that
470 # changes to the program text of functions that BuildIspcDsoSource()
471 # calls should also trigger a change. For example, adding a

481 # the readability of an already fairly complicated function.
