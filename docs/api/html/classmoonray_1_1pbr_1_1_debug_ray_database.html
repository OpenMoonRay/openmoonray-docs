Detailed Description

The DebugRayDatabase class is really just a container for the data generated by the DebugRayBuilder. See DebugRayBuilder for further comments about what each member vector contains.

In addition, it provides filtering and iteration functionality, as well as the ability to serialize/deserialize itself.
