Convenience function that evaluates an attribute triplet: color, factor and boolean toggle. This is a very common case in material shaders (ex: "diffuse color", "diffuse factor", "show diffuse"). This function will only try to evaluate the color attribute if the boolean toggle is on and if the factor attribute is non-zero. This function returns the product of the three.
