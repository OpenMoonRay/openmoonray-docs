13/*
14 * Moonray's volume cutouts (a.k.a. holdouts) are based on the book:
15 * "Production Volume Rendering, Design and Implementation" by Wrenninge.
16 * See Section 10.8, specifically Code 10.6.
17 *
18 * The CutoutVolume works the same way as the CutoutMaterial. It has an
19 * indirect volume attribute that is a regular volume shader. This shader is
20 * used for non-primary rays (that we don't cutout), ensuring correct indirect
21 * illumination. CutoutVolume just wraps the indirect volume shader and overrides
22 * the isCutout() virtual function to tell Moonray's PathIntegratorVolume to
23 * invoke cutout behavior when integrating / ray marching.
24 */
25
