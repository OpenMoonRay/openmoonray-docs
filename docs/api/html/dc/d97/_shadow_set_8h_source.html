15/**
16 * The ShadowSet inherits from the LightSet. Just like the LighSet, it is a
17 * collection of lights with no duplicates. It it used for per part assignments
18 * in the Layer. It can be reused for multiple Layer assignments.
19 *
20 * The purpose of the ShadowSet is to specify which lights an object does not cast
21 * a shadow from. For example ObjectA is assigned LightSetA. LightSetA contains LightA
22 * and LightB. ObjectA is also assigned ShadowSetA, which contains just LightA. This setup
23 * means ObjectA is illuminated by LightA and LightB, but is only casts a shadow from LightB.
24 */
25class ShadowSet : public LightSet
