74class RenderOutputWriter
75//
76// This class is used for writing RenderOutputData.
77// This class executes 3 different runMode (STD, ENQ, and DEQ) internally and has 2 different types of
78// constructors based on the runMode. You should select one of them depending on the runMode.
79//
80// runMode STD : standard run mode. output files are immediately written out inside main() call.
81// runMode ENQ : enqueue data into the cache. ImageWriteCache is created instead of written out to the disk.
82// The actual file write action is postponed later and executed by the imageWriteDriver thread.
83// runMode DEQ : Called from imageWriteDriver and execute cache data write action.
84//
85{

170 //
171 // Return result of write action.
172 // Usually, scene includes multiple file output. This API tries to do write-out actions for all files.
173 // This API supports 3 modes (STD, ENQ, and DEQ).
174 // STD and DEQ execute actual write-out action.
175 // ENQ only creates cache data.
176 //
177 // Return true when all of the writing files action succeeded.
178 // Return false if some of (or all of) the writing files action failed.
179 // Partial failed condition case, some of the file writing action might be succeeded without error.
180 // We don't stop writing action when we hit the first error, and we will try to write the data as much
181 // as possible.
182 //
183 bool main() const;
