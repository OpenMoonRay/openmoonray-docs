76/**
77 * The RenderContext is the top level access point to rendering services
78 * provided by the MOONRAY renderer. To do rendering, you create a RenderContext.
79 *
80 * Right now the RenderContext will only check the RDL scene and DSO path when
81 * its created. If you want to change scenes or change the DSO path, you'll
82 * need to destroy the context and recreate it.
83 *
84 * Some options are only configurable until the first render, such as the
85 * layer. Once we start rendering, we've built data structures
86 * assuming such options won't change.
87 *
88 * The width and height *should* be configurable between each frame, as long
89 * as you are not rendering while changing them.
90 *
91 * Updates to scene data or geometry can be applied by calling the appropriate
92 * update function. These also need to be called while not rendering.
93 */
94class RenderContext
