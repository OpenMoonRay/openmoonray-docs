47/**
48 * The Layer is a subclass of the TraceSet. It stores material and light
49 * assignments to parts on a Geometry. Each assignment is made up of the
50 * following tuple:
51 * (Geometry*, String, Material*, LightSet*, Displacement*, VolumeShader*)
52 *
53 * The Geometry and part name String uniquely identify a particular assignment,
54 * while the Material and LightSet are the values of the assignment.
55 *
56 * When the assign() method is called, it returns a 32-bit unsigned integer.
57 * This is the assignment ID. It is unique for a particular Geometry/Part pair.
58 * It can be used to quickly and efficiently look up the assigned Material
59 * and LightSet.
60 *
61 * If you only have the Geometry and part name String, you can still look up
62 * assignments, but it will be much slower than using an assignment ID. If you
63 * lose the assignment ID, you can get it again by using the assignmentId()
64 * method. Make sure to save it this time, though, because finding the
65 * assignment ID is what's slow, so find the ID and looking up the assignment
66 * is just as a slow as directly looking up the assignment by Geometry/Part.
67 *
68 * Calling the assign() method again with an existing Geometry/Part pair will
69 * result in a reassignment of the Material and LightSet to that assignment.
70 * It will return the same assignment ID as the previous assignment that was
71 * there before.
72 */
