class  moonray::pbr::BsdfSampler
 A BsdfSampler object is a helper class used to efficiently sample multi-lobe bsdfs, using Veach's multi-sample model. It uses lobe importance sampling, but also helps the integrator to preserve good stratification of lobe sampling, giving at least one sample per active lobe, at most one sample per mirror lobe, and a variable number of samples for other lobes.
