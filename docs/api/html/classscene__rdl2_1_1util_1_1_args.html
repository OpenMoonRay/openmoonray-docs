Parses a specific option and its (one or many) values out of command-line arguments. "flag" is the name of the flag you're looking for (including the leading dash), "numValues" is how many values you expect to follow the flag (-1 for any number of values). startIndex allows you to skip some number of leading arguments, which can be useful for flags which may occur multiple times. It will return the index in args at which the flag was found (-1 if it was not found), and the values following the flag will be placed into "values". The function may throw in case of parsing error
