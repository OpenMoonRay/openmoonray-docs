21class ProcKeeper
22//
23// This class boots a thread and this thread is in charge of write-progress-update and signal-based
24// SceneContext dump.
25//
26// Basically, inside a signal handler, we can only execute async-signal-safe functions and it is not
27// enough for executing the desired actions at signal received time.
28// Instead, we set up an internal flag of this class from signal handler. And the thread which is
29// booted by this class's constructor executes the main actions that we need.
30// Under this solution, we basically can run any code without getting any limitations of a signal
31// handler when we received the signal.
32// Also, we can pretty easy to add other signal actions to this class if we need in the future.
33//
34{
35public:
