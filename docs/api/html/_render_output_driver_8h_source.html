39/// A class that can interpret the contents of a set of
40/// RenderOutput objects (that are possibly inconsistent), resolve
41/// them into a consistent set, query information about them such as
42/// "needs heat map results" and ultimately output the results

94 /// Aov schema - This array contains the ordered list of aov schema Ids
95 /// in the Film's aov buffer. For example, if the schema contains
96 /// three entries as:
97 /// schema[0].mId = AOV_SCHEMA_ID_STATE_P
98 /// schema[1].mId = AOV_SCHEMA_ID_STATE_ST
99 /// schema[2].mId = AOV_SCHEMA_ID_STATE_DSDX
100 /// Then the aov buffer is expected to have 3 entries laid out
101 /// as:
102 /// aovBuffer[0] = Float3Buffer (P.x, P.y, P.z)
103 /// aovBuffer[1] = Float2Buffer (St.x, St.y)
104 /// aovBuffer[2] = FloatBuffer (dsdx)
