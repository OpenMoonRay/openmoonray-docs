20// This program supports a somewhat hack-y way of allowing ISPC to interact
21// with C++
22//
23// ISPC receives pointers to various rdl2 things (SceneObject's, Map's,
24// Shadeable's). It needs to be able to access data that lives inside these
25// objects (mostly parameters and bindings), but it cannot do so via the
26// rdl2 standard type definitions because it cannot consume these types -
27// they are C++.
28//
29// So, this program instantiates the rdl2 objects of interest (somewhat
30// surreptitiously with this asOFFSET() trickery), then emits out the
31// byte offsect of the members in a form that can be used as a header
32// file that ISPC can read in.
33//
34// The usage is intended to be:
35// 1) build system should compile this file
36// 2) build system should run the executable this file produces...
37// 3) ...piping its output to a ISPCrdl2Helper.h or similar file
38// 4) then ISPC files can pull it in
39
40int main(void) {

45#endif
