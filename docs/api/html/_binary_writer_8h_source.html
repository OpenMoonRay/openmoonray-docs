26/**
27 * A BinaryWriter object can encode a SceneContext into a binary stream of RDL
28 * data. It can be used to save a SceneContext to a serialized file,
29 * create incremental updates sent over a network socket, etc.
30 *
31 * BinaryWriter doesn't need to make any modifications to the SceneContext, so
32 * it operates on a const (read-only) context. It must have a consistent view
33 * of the context, however, so you can't write to objects in another thread
34 * the BinaryWriter is running.
35 *
36 * The BinaryWriter can output binary data to a number of sinks. There are
37 * convenience functions for writing RDL data to a file or a generic output
38 * stream. These methods handle proper framing of the RDL binary data. The
39 * method which writes binary data directly to byte strings assumes the
40 * framing will be added later by the caller.
41 *
42 * RDL framing is very simple, so if you want to handle it at a higher level
43 * and write directly to byte strings it's not very hard. The frame looks
44 * like this:
45 *
46 * +---------+---------+------------+------------+
47 * | mlen | plen | manifest | payload |
48 * +---------+---------+------------+------------+
49 * | 8 bytes | 8 bytes | mlen bytes | plen bytes |
50 * +---------+---------+------------+------------+
51 * ^-- first byte last byte --^
52 *
53 * NOTE: Both mlen and plen are 64-bit unsigned integers, in network byte
54 * order (big endian).
55 *
56 * Thread Safety:
57 * - Since the BinaryWriter reads SceneContext data (in particular,
58 * SceneObjects), it is not safe to be writing to SceneObjects in another
59 * thread while the BinaryWriter is working.
60 *
61 * Scene contexts can be written in "rdlsplit" mode, where non-vectors and small vectors
62 * are placed in an rdla file, and large vectors are placed in a parallel rdlb file.
63 * To support this, if you call setSplitMode(N), then only vector attributes of size >= N
64 * will be written.
65*/

98 /**
99 * Turns on optimizations for encoding deltas of changed data. This results
100 * in major data compression and improvements in decoding speed. The final
101 * data is reliant on attribute default values defined in the rendering
102 * DSOs and values that have not changed since the last commit.
103 *
104 * If you are encoding data to be sent over the wire and immediately
105 * consumed, turn on delta encoding. If you're encoding data to be stored
106 * on disk and want newer DSOs to supply new default values, turn on delta
107 * encoding. If you're encoding data to be stored on disk and want
108 * absolutely all values (including defaults) written to the file, turn
109 * delta encoding off.
110 *
111 * @param deltaEncoding True to enable delta encoding, false to disable
112 * it. (Disabled by default.)
113 */
114 finline void setDeltaEncoding(bool deltaEncoding);

116 /**
