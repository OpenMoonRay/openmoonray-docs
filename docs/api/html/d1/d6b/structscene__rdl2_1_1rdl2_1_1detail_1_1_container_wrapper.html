Detailed Description

template<typename Container>
class scene_rdl2::rdl2::detail::ContainerWrapper< Container >

This class is similar to std::reference_wrapper. It exists because concrete references to the RDL containers in the Layer aren't stored, but are accessed through get() calls. The iterators provided on the Layer need to be able to refer to the containers.
