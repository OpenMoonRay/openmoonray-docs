Detailed Description

The LineSegments class is a Curves primitive representing group of "chains" of linear line spans. Each chain can have varying number of vertices, and adjacent vertices in a chain form a line span.

The primitive needs to implement getSubPrimitiveCount, getBoundsFunction, getIntersectFunction, getOccludedFunction for BVH as ray tracing kernel if canIntersect return true, otherwise it needs to implement tessellate to generate sub primitives renderer can put in BVH for ray tracing
