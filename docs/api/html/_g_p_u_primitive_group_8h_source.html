44 // The GPUTriMesh objects are the host-side representation of the triangle meshes
45 // on the GPU. They manage the memory on the GPU and provide functionality needed
46 // on the host side to constuct the BVH, such as AABB queries.
47 // TriMeshes are hardware-accelerated (ray-triangle intersection) and are a special
48 // case in Optix that can't be mixed with other types of primitives. You do not
49 // need to specify an "intersection" program for triangle meshes because it is baked
50 // into the GPU.
