Detailed Description

The GeometrySet represents a collection of Geometries with no duplicates. It's used for building BVHs over a set of spatially local Geometries, where building trees for each Geometry would result in a lot of spatial overlap.

It only has one attribute, named "geometries", which is a SceneObjectIndexable. We provide convenience functions on the GeometrySet to add and remove Geometries from the set, as well as check if a Geometry is contained in the set. Please use these functions to maintain the geometries' uniqueness invariant. When setting "geometries" directly, make sure the light filters are unique and their order is deterministic.

You can get the Geometries as a const SceneObjectIndexable& with the getGeometries() method call.
