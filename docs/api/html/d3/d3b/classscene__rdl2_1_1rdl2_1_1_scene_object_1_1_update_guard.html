Detailed Description

RAII guard for updating attributes on a SceneObject.

Since all attribute updates must be done between beginUpdate() and endUpdate() calls, this guard can guarantee safe usage even in the presence of exceptions and other thrilling control flow surprises.

The constructor calls beginUpdate() on the passed SceneObject and the destructor calls endUpdate().
