29/**
30 * Displacement, CameraProxy, EnvMapProxy, GeometryProxy, LightProxy, LightFilterProxy,
31 * MapProxy, MaterialProxy, VolumeShaderProxy and SceneObjectProxy define proxy classes
32 * for objects of each customization point in RDL2.
33 *
34 * Effectively these objects will invoke the proper chain of constructors and
35 * have the same set of attributes as the objects they are standing in for,
36 * but don't provide the rich interface of those objects. As such, they don't
37 * drag in any library dependencies.
38 *
39 * This is useful if you want to create objects of those types, but don't want
40 * to link with or distribute the huge chain of dependencies that your DSOs
41 * might have. Those are still needed for rendering, but for a content tool
42 * which just needs to set attribute data those dependencies are overkill.
43 *
44 * Built in classes that come for free with RDL (like the GeometrySet, Layer,
45 * LightSet, and SceneVariables) never need to be proxied, because they are
46 * always fully available and have no extra dependencies.
47 */
