Sample a child map from a parent shader.

This header contains low-level API calls to run shaders (material, map, displacement, etc.). These API calls are used by rendering applications to call shaders directly (integrator, displacement mapping) or by high-level functions that allow shaders to evaluate their attributes bound to other map shaders (See: EvalAttribute.h)
