Detailed Description

Derived class to implement the Normalized Diffusion Bssrdf with importance sampling.

This Bssrdf implements "Normalized Diffusion" approximation as described in: [1] "Approximate Reflectance Profiles for Efficient Subsurface Scattering", Burley Christensen, Pixar Technical Memo #15-04 - July, 2014 http://graphics.pixar.com/library/ApproxBSSRDF/paper.pdf

[2] http://www-history.mcs.st-andrews.ac.uk/history/HistTopics/Quadratic_etc_equations.html
