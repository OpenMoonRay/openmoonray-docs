11/*
12 * This file is used to compensate for energy loss from
13 * microfacet reflection lobes as outlined in Walter'07.
14 * We use the Kelemen'01 energy compensation BRDF as described in
15 * Kulla'17 to be added to the regular microfacet BRDF.
16 * This file describes the term to be added in reflection
17 * to be perfectly energy 'preserving'. It also provides
18 * sampling curves, PDF and a one-sample weight to sample
19 * this term efficiently.
20 * Ref:
21 * Revisiting Physically Based Shading, PBS Kulla'17
22 */
