73// class ChannelAlias
74//
75//============================
76//-----------------------------------------------------------------------------
77//
78// :ref:`channelcontext_class` stores a list of these structures to map
79// channel names to channel indices and vice-versa.
80//
81// There should be one of these for every available ChannelIdx that can be
82// accessed by a ChannelSet. There can be ChannelAliases in multiple
83// ChannelLayers that point to the same ChannelIdx, but there's always a
84// single global list of ChannelIdx's.
85//
86// This allows channels from multiple Parts & files to have different
87// names (aliases) but still align for compositing operations.
88// Ex.'rgb' and 'rgba' layers both refer to the same Chan_R/Chan_G/Chan_B
89// ChannelIdx's, but 'rgba' also includes Chan_A.
90//
91// Nested layers are informally supported by always considering the last
92// period '.' in the channel name to be the layer/channel separator, so
93// the layer name can have multiple separators describing the nesting.
94// ex. beauty.diffuse.R
95//
96//-----------------------------------------------------------------------------
97
