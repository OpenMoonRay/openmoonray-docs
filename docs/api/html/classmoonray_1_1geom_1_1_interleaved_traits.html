Detailed Description

template<typename T, typename Allocator = scene_rdl2::alloc::AlignedAllocator<T, SIMD_MEMORY_ALIGNMENT>>
class moonray::geom::InterleavedTraits< T, Allocator >

Provides a vertex buffer layout in which each time sample is interleaved. E.g. (at0, at1, bt0, bt1, ct0, ct1, ..., zt0, zt1)

Remarks
Implementation detail for internal memory layout.
