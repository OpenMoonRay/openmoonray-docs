# ColorCorrectDisplayFilter

****

Documentation for class ColorCorrectDisplayFilter



---

## <p style="color:blue;">Advanced attributes</p>

## invert_mask

**Bool** 


Default value : False




invert value of mask




## mix

**Float** 


Default value : 1.0




blend between output and input






---

## <p style="color:blue;">General attributes</p>

## contrast

**Float** 


Default value : 0.0




Decrease contrast below 0.0 and increase contrast above 0.0




## exposure

**Float** 


Default value : 0.0




Adjusts the exposure, in fstops




## gamma

**Float** 


Default value : 1.0




Adjusts gamma of input




## input

**67141632** 


Default value : None




RenderOutput to color correct




## mask

**67141632** 


Default value : None




<p style="color:red;">Documentation for the attribute <b>mask</b> needs to be written</p>




## multiply

**Rgb** 


Default value : [ 1, 1, 1 ]




Multiplies input using specified color




## offset

**Rgb** 


Default value : [ 0, 0, 0 ]




Add offset color to input




## saturation

**Float** 


Default value : 1.0




Desaturates input below 1.0 and adds saturation above 1.0
