# ShadowDisplayFilter

****

Documentation for class ShadowDisplayFilter



---

## <p style="color:blue;">General attributes</p>

## density

**Float** 


Default value : 1.0




Blend value between occluded and unoccluded images. 1 = completely occluded. 0 = completely unoccluded.




## occluded

**67141632** 


Default value : None




Image Buffer representing the occluded image




## shadow_color

**Rgb** 


Default value : [ 0, 0, 0 ]




color of the shadow




## unoccluded

**67141632** 


Default value : None




Image Buffer representing the unoccluded image
