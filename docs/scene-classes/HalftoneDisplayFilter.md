## <p style="color:blue;">General attributes</p>

## filter_width

**Float** 


Default value : 1.0




The width in pixels of the antialiasing




## grayscale

**Bool** 


Default value : False




Ignore color information, render as grayscale




## input

**67141632** 


Default value : None

## invert

**Bool** 


Default value : False




Whether the dots should be black (normal) or white/color (inverted)
