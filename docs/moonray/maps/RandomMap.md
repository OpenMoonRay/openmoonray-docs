# RandomMap
**MAP SHADER**

---

<details open>
<summary class="scene-class-attr-group">General attributes</summary>

<h2>input</h2>
<b>Rgb</b>  *bindable*

Default value : [ 1, 1, 1 ]  

the input color used as a base seed to generate the random value


<h2>monochrome</h2>
<b>Bool</b>  

Default value : True  

outputs the same color for all three channels


<h2>output_max</h2>
<b>Float</b>  

Default value : 1.0  

the maximum output random value


<h2>output_min</h2>
<b>Float</b>  

Default value : 0.0  

the minimum output random value


<h2>seed</h2>
<b>Int</b>  

Default value : 0  

additional seed added to input for random number generator


</details>
