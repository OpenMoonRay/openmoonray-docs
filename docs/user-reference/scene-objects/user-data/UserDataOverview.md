An object used to encapsulate arbitrary, user-specified primitive attributes.  Geometry objects
can specify a list *UserData* objects using the *primitive_attributes* parameter.  The data is then
available for shading or AOVs using an
[AttributeMap]({{ "/user-reference/scene-objects/maps/AttributeMap" | absolute_url }}).  See 
[RdlPointGeometry]({{ "/user-reference/scene-objects/geometry/RdlPointGeometry" | absolute_url }}) for an example.
