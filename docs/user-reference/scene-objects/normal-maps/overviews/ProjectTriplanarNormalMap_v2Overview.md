**ProjectTriplanarNormalMap_v2** has the same behavior as [ProjectTriplanarNormalMap]({{ "/user-reference/scene-objects/normal-maps/ProjectTriPlanarNormalMap" | absolute_url }}) with one exception.   Instead of the *use_reference_space* attribute, v2 has *input_position_source* which can use the surface position and normal, the reference position and normal, or a custom position and normal defined by the *input_position* and *input_normal* attributes respectively.
