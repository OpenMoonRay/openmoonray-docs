The <span class="define">DwaSkinMaterial</span> is a specialized version of the [DwaSolidDielectricMaterial]({{site.baseurl}}/user-reference/scene-objects/materials/dwa/DwaSolidDielectricMaterial) intended to be used for skin. The only difference is that the extra clearcoat specular lobe is labeled as a moisture lobe and the _clearcoat_bending_ attribute is removed.
