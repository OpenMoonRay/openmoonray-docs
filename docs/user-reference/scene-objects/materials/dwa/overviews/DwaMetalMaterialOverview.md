The <span class="define">DwaMetalMaterial</span> is designed to create any metallic materials such as gold, copper, chrome, and steel. It is best to use physical values for the _metallic_color_ and _metallic_edge_color_ in order to create a realistic looking metal. Generally, the _metallic_edge_color_ is a brighter version of the _metallic_color_ and these two parameters define the conductor Fresnel behavior unique to the DwaMetalMaterial.
