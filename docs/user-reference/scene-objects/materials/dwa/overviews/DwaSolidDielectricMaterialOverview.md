The <span class="define">DwaSolidDielectricMaterial</span> is the general purpose material for all opaque non-metal surfaces. Use this material for everything such as wood, paint, plastic, stone, clay, etc. For transparent materials such as glass, water, and gemstones, see the [DwaRefractiveMaterial]({{site.baseurl}}/user-reference/scene-objects/materials/dwa/DwaRefractiveMaterial). For metallic materials, see the [DwaMetalMaterial]({{site.baseurl}}/user-reference/scene-objects/materials/dwa/DwaMetalMaterial).
