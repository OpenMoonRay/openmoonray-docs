# Light Filters in MoonRay

Light filters modulate the output of a light by multiplying the light's radiance by a filter value.
This provides more precise, customized control over the light's emission.

There are 9 types of light filters supported in MoonRay:
* [BarnDoorLightFilter]({{ "/user-reference/scene-objects/light-filters/BarnDoorLightFilter/" | absolute_url }})
* [ColorRampLightFilter](    {{ "/user-reference/scene-objects/light-filters/ColorRampLightFilter/"     | absolute_url }})
* [CombineLightFilter]( {{ "/user-reference/scene-objects/light-filters/CombineLightFilter/"  | absolute_url }})
* [CookieLightFilter](     {{ "/user-reference/scene-objects/light-filters/CookieLightFilter/"      | absolute_url }})
* [CookieLightFilter_v2](    {{ "/user-reference/scene-objects/light-filters/CookieLightFilter_v2/"     | absolute_url }})
* [DecayLightFilter](    {{ "/user-reference/scene-objects/light-filters/DecayLightFilter/"     | absolute_url }})
* [IntensityLightFilter](  {{ "/user-reference/scene-objects/light-filters/IntensityLightFilter/"   | absolute_url }})
* [RodLightFilter](    {{ "/user-reference/scene-objects/light-filters/RodLightFilter/"     | absolute_url }})
* [VdbLightFilter](    {{ "/user-reference/scene-objects/light-filters/VdbLightFilter/"     | absolute_url }})
