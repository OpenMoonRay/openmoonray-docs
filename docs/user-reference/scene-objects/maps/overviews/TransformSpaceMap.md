The *TransformSpaceMap* is used to transform data from one space to another.
For example, binding an 
[AttributeMap]({{ "/user-reference/scene-objects/maps/AttributeMap" | absolute_url }})
to the *input* parameter, we can transform *P* from render space to world space or *N* from
world space to local tangent space.   For an in depth explanation of the *instance level*
spaces see the
[how-to guide]({{ "/user-reference/how-to-guides/instance-level-transforms" | absolute_url }}).
