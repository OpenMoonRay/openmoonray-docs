**ExtraAovMap** is used together with the 
[ListMap]({{ "/user-reference/scene-objects/maps/ListMap" | absolute_url }})
to evaluate arbitrary
[maps]({{ "/user-reference/scene-objects/maps" | absolute_url }})
and output the result to an extra aov using an LPE label.  This map should be bound to one of the *map0*-*map19* parameter of a ListMap.
