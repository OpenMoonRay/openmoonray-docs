Th *UsdTransform2d* map is part of the [USD Preview Surface](https://openusd.org/release/spec_usdpreviewsurface.html) 
spec.  It's primary purpose is to transform st coordinates which are input from a [UsdPrimvarReader_float2](../UsdPrimvarReader_float2)
and output them to a [UsdUVTexture](../UsdUVTexture) map.
