# User Reference

Once you have perused the [Getting Started Guide](../getting-started/) for information on how to install and run MoonRay, refer to this section for further information on how to use it. 

This reference guide includes the following:
- **Execution Modes**: A dive into MoonRay's different execution modes.
- **Scene Objects**: A comprehensive collection of MoonRay's scene objects, along with their attributes and defaults. You might also find usage examples in MoonRay's RDLA scene description format.
- **How-to Guides**: More involved descriptions of how to leverage MoonRay to achieve a certain effect or purpose. While "Scene Objects" may contain the general attribute reference, "How-to Guides" gives a more in-depth explanation of what the scene objects and their attributes do. 
- **Tools**: A look at the provided MoonRay-adjacent tools, including its denoiser, hydra delegate, user interface, command-line tool, and render profile viewer. 
- **Maximizing Performance**: Some tips & tricks on how to get the best performance out of MoonRay.
